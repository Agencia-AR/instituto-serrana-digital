# 11. MVP — prioridade MoSCoW

## MUST

- portal;
- Home Santa Rita;
- Bolerata;
- eventos;
- Sympla read/sync;
- auth;
- dashboard;
- CRM;
- financeiro básico;
- segurança;
- responsividade.

## SHOULD

- atendimento WhatsApp;
- mapas;
- documentos;
- projetos;
- check-in.

## COULD

- Instagram;
- patrocinadores avançado;
- IA mais autônoma;
- NFS-e;
- conciliação.

## WON'T NOW

- app nativo;
- checkout próprio;
- contabilidade completa;
- folha.

---

# 12. Definition of Ready

Item pode entrar em desenvolvimento quando:

- objetivo claro;
- usuário definido;
- regra definida;
- dependência identificada;
- design disponível;
- aceite definido;
- segurança avaliada.

---

# 13. Definition of Done

- code review;
- testes;
- responsivo;
- acessível;
- logs;
- security;
- docs;
- QA;
- deploy staging;
- aprovação.

---

# 14. Riscos

| Risco | Ação |
|---|---|
| escopo amplo | MVP rigoroso |
| dependência Sympla | adapter + contrato |
| WhatsApp não oficial | oficial como baseline |
| mídia pesada | otimização |
| conteúdo não validado | PROPOSTA/CONFIRMADO |
| dados dispersos | discovery/migração |
| permissões | RBAC/RLS |
| IA | human-in-the-loop |
