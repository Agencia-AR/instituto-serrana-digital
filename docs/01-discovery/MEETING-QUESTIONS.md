# Reunião de Descoberta — perguntas

Use quatro estados para cada item:
- CONFIRMADO
- HIPÓTESE
- PENDENTE
- DECISÃO

## Institucional
- Qual nome deve aparecer como marca principal?
- Confirmar missão, visão e valores.
- Confirmar diretoria atual.
- Quais áreas de atuação devem ter maior destaque?
- Quais projetos entram no lançamento?
- Quais documentos serão públicos?

## Bolerata
- Como é a operação real de mesas?
- Cada mesa/cadeira corresponde a qual item no Sympla?
- Existem cortesias, patrocinadores e bloqueios?
- Existem plantas ou medidas oficiais?
- Como ocorre check-in?
- Como ocorrem cancelamentos e alterações?

## Ferramentas
- Sympla: plano, contrato, acessos.
- WhatsApp: número, Meta Business, API atual.
- Instagram/Facebook.
- Financeiro.
- NFS-e.
- Banco/contabilidade.
- Armazenamento.
- Planilhas atuais.
