# Protótipo para a reunião de descoberta

## Objetivo

Não chegar à reunião apenas com perguntas. Levar uma proposta visual navegável, marcada como **PROPOSTA**, para acelerar validação.

## Telas prioritárias

1. Home — base da escadaria → Santa Rita.
2. O Instituto.
3. Projetos / áreas de atuação.
4. Bolerata.
5. Página de edição.
6. Mapa de mesas — Conceito A urbano.
7. Mapa de mesas — Conceito B operacional.
8. Login / Área do Instituto.
9. Dashboard.
10. CRM.
11. Financeiro.
12. Mobile essencial.

## O que deve estar pronto antes da reunião

- paleta;
- tipografia;
- tokens básicos;
- header;
- botões;
- cards;
- estados de mesa;
- sidebar admin;
- cards de KPI;
- pipeline de CRM;
- uma navegação clicável.

## O que não precisa estar pronto

- banco;
- autenticação real;
- integrações reais;
- checkout;
- emissão fiscal;
- sincronização Sympla;
- IA em produção.
